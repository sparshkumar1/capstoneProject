# capstonePapers/ — scope note

Historical PDF export snapshots of an ADCOM2027 (Springer CCIS format) submission draft of this project's research paper, kept as a version history of that submission track. These are generated outputs (not source), superseded by the maintained source in `ADCOM2027_Track2_Final/` and, for the current IEEE-format paper, `paper/manuscripts/` and `final_deliverables/05_IEEE_Paper/`.

| File pattern | What it is |
|---|---|
| `ADCOM2027_PREPAIred_v13_1_SUBMISSION_*.pdf`, `v8_complete_blind.pdf` | Submission-track exports of an ADCOM2027 draft (anonymous/blind and master variants) |
| `PrepAIred_ADCOM2027_Springer_CCIS_*.pdf` | Successive revision passes of the same manuscript in Springer CCIS format |

None of these are read by application code; they are archival snapshots of a paper-writing process. For the currently active, maintained version of this research line, see `ADCOM2027_Track2_Final/` (has its own `README.md` and build source) rather than these static exports.
