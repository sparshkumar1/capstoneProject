# Details/ — scope note

This directory holds source/reference material supplied for the university capstone deliverables, not application code or generated output.

| File | What it is |
|---|---|
| `PPT-Template_Phase3- Review3.pptx` | The official PES University Phase-3 "Project Progress Review 3" presentation template (branding/slide-master source). Used, not modified, by `final_deliverables/04_Final_Presentation/` builds. |
| `Report- Guidelines.pdf` | The official PES University report-formatting guidelines (margins, fonts, chapter structure) that `final_deliverables/02_University_Project_Report/` was built to follow. |
| `revised_report_v5.pdf` | An earlier (Phase-2-era) project report, kept as a historical reference and comparison baseline — see `reference_material_analysis/Previous_Project_Report_Analysis.md` for the discrepancy analysis performed against it. |
| `Report initial Pages(Pg 1-10)` | Earlier front-matter pages from a prior report draft, kept for reference. |
| `Coordination_Specialization_and_Bounded_Authority_in_Adaptive_Technical Interview_Systems_A_Replay_Based_Decomposition_Study (1).pdf` | A separately-supplied research-paper draft describing a multi-agent coordination layer. **This architecture was independently verified not to exist in the deployed codebase** (no second decision-making agent, no arbitration module) and is explicitly excluded from this project's own paper/report/presentation deliverables — kept here only as the original source material for that finding, not as a description of the real system. |

Nothing in this directory is read by application code at runtime; it is reference/template material only.
