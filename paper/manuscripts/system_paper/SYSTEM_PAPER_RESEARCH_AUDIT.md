## Bottom line
- What exists is an integrated **audio + text** prototype with a PPO+guardrail difficulty controller, a code sandbox and a local feedback model. It is not "multimodal" in the video sense, and even the audio channel reaches adaptation only through a confidence score.
- Evidence exists for parts (sandbox behaviour, exploratory evaluator agreement, simulated controller equivalence). **No evidence exists about the integrated system's effect on any person.** The only honest present description of the system paper is a pre-research design plus a system description.
- Two findings need an author decision before any study: (1) the runtime hesitation input is derived from confidence, so a study of a "confidence and hesitation" adaptation loop would not test what the design documents describe unless the hesitation scorer is wired in; (2) no runtime study arms (Constant-Same, rule-only) exist.
- Wiring the hesitation scorer or adding study arms would change the deployed system and, if it touched the state, would create a runtime/training mismatch with the frozen PPO checkpoint. Neither has been done; both need explicit approval (CLAUDE.md: no change to state definitions or PPO without approval).

## Title consequence
"Multimodal" is **not justified** by the present implementation (audio and text only, hesitation not wired, video absent). The working title stays provisional; see `SYSTEM_PAPER_RQ.md`.
