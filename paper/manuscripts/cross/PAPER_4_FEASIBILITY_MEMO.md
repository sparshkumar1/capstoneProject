# Paper 4 feasibility memo (2026-09-21)

**Recommendation: NO FOURTH PAPER.** There is no independently defensible research question, contribution or evidence base for one today, and creating a manuscript for publication count is not justified.

| Question | Answer |
|---|---|
| 1. What new research question would Paper 4 answer? | None that is not already P1, P3, the system paper or the held P2. |
| 2. What evidence would be unique to it? | None exists. Candidate directions below all need data that do not exist. |
| 3. What contribution would not already belong to P1/P3/System? | None identified. Splitting the system study into "usability" and "outcome" papers would be a thin split of one experiment. |
| 4. New dataset needed? | Only for a benchmark paper: a genuinely reusable, consented, anonymized, annotated dataset with quality controls, which the system study might produce if designed for it. Not now. |
| 5. New participant study needed? | Yes for any human-facing direction (that study is the system paper's). |
| 6. New algorithm needed? | Not established; none proposed. |
| 7. Suitable venue? | Not assessed; nothing to place. |
| 8. Overlap risk? | High: any Paper 4 drawn from the current evidence would repeat P1, P3 or P2. |
| 9. Worth the extra burden? | No. The remaining effort is better spent on the system paper's study and on P1/P3 confirmation. |

## Directions that could become papers later, only if new evidence creates them
- **Dataset/benchmark:** only if the human study yields a reusable, properly consented and documented set of answers and ratings.
- **Evaluator paper (the held P2):** revive only after rater provenance, consent/ethics records and cross-encoder provenance are established and an independent contribution beyond the exploratory measurement exists (for example the new documented rating round in `research/audit/X2_PROTOCOL_DRAFT.md`, which is unexecuted).
- **Artifact/reproducibility paper:** only if a released toolkit is itself a useful research artifact and a venue accepts that type.
