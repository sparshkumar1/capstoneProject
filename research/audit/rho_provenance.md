# Forensic Provenance: Spearman $\rho = 0.6975$ vs $\rho = 0.7400$

**Audited Commit:** `9cfd34f`  
**Purpose:** Reconcile the discrepancy between reported correlation values $\rho = 0.6975$ and $\rho = 0.7400$ on the pilot human evaluation set.

---

## 1. Executive Forensic Finding

The two values arise from **evaluating different data sources for the predicted score**:

1. **$\rho = 0.6975$ ($r = 0.7290, \text{MAE} = 0.2245$):**
   - **True Live Code Execution.** Generated by calling the live production evaluation function `services.evaluator.app.evaluate(question, candidate_answer, rubric)` on all 20 records in `ablation/results/ratings_rater1.csv`.
   - Uses the active codebase parameters: $w_{S1}=0.15, w_{S2}=0.35, w_R=0.50$, $\theta = 0.30$, reasoning dampening $R \le 0.30 \implies S_2 \times 0.60$, and mandatory concept capping.
2. **$\rho = 0.7400$ ($r = 0.6690, \text{MAE} = 0.2092$):**
   - **Static CSV Artifact.** In `ablation/results/ratings_rater1.csv`, there exists a pre-recorded column named `system_score` saved during early exploratory experiments in June 2026.
   - For rows 0, 10, and 16 (empty/blank answers), `system_score` was blank (`NaN`).
   - When `analyze_human_ratings.py` read this static CSV and executed `df["system_score"].fillna(0.0)`, the resulting static column had a Spearman correlation of $0.7400376$ with `human_score`.

**Conclusion:** **$\rho = 0.6975$ is the authentic, reproducible scientific metric** of the actual live evaluator codebase. $\rho = 0.7400$ is an artifact of an older static CSV column with post-hoc `.fillna(0.0)`.
