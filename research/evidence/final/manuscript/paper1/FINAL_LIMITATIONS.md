## Four HIGH limitations (all four must appear)
1. Numeric sanitization: NaN, Inf and negative evaluator outputs currently become 0.0 rather than being classified as infrastructure failures. FLT-04 is only a numeric-range sanitization observation, not robust corruption/failure detection.
2. Follow-up channel: the X1-B-I test did not test the separate Qwen follow-up generation channel in which generated follow-up text and target concepts can enter the evaluator's expected-concepts path. Do not claim that all Qwen influence paths are contained or irrelevant to scoring.
3. ptrace: SEC-01 containment depended on literal preflight filtering in the tested path; after bypassing the filter, ptrace(TRACEME) returned 0 in the container. Do not describe the result as intrinsic universal ptrace isolation by Docker.
4. Qwen timeout: the shipped Qwen client timeout is 6 seconds, while local CPU generation during the experiment took approximately 19-30 seconds (the UI abandons an evaluation after 20 s). Latency observations from local generation must not be presented as evidence that the shipped 6-second service path can complete those generations within its configured timeout.

FLT-08 (WebSocket) and FLT-09 (audio) were not executed. SEC-09: the permissive-control canary reset had a methodological flaw. Single environment only (Windows 11 + WSL2 + Docker Desktop + local image); no cross-platform generality. Single-agent design/execution bias and limited independent perturbation controls.

## Threats to validity
- Construct validity: author-written attack programs, oracles and controls; executor status strings are non-discriminating for SEC-02/07/08/09, so containment rests on host/runtime observables; SEC-08 oracle references a SUT constant; SEC-09's canary criterion is not discriminating in the shipped configuration and its permissive-control canary reset was flawed; some SLAs are derived from SUT constants; the static pre-flight is a literal-pattern filter (only the literal ptrace( spelling tested).
- Internal validity: the same agent designed, registered (local, unpushed, author-controlled tags), ran, repaired and re-tested the campaigns (repair-and-retest is a regression check, not an independent replication); v2/v3 reruns were written after earlier results were seen; FLT-01 and FLT-07b timing bounds are marginal; Qwen path tested with a fixed evaluator stub, a name-based static guard, replayed-text mutation control, unseeded generation and a client timeout raised to 600 s.
- External validity: one environment; nine finite attack programs; enumerated fault scenarios (FLT-08/09 not executed); 36 single-sentence injections whose steering effect on the model is not demonstrated; the follow-up-question channel is an untested LLM-to-evaluator dependency; B2 not run.
- Conclusion validity: deterministic repetitions give repeatability counts (5/5), not rates or intervals; no statistical inference is claimed; the project .venv violates its pins (registry X-C004).
