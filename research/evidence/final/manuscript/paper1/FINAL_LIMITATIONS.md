# Paper 1 - limitations to state in the paper
Single machine (Windows 11, Docker Desktop WSL2, default seccomp); nine finite attack programs; deterministic repetitions (counts, not rates); the same agent designed, registered (local, unpushed, author-controlled tags), ran, repaired and re-tested the campaigns, and only a self-audit exists; v2/v3 reruns were written after earlier results were seen; the static pre-flight is a literal-pattern filter and ptrace returned 0 in the container when it was bypassed; SEC-09's canary criterion is not discriminating in the shipped configuration and SEC-08 uses the configured pids constant; status strings do not distinguish contained from breached for four attacks; FLT-01 and FLT-07b timing bounds are marginal; FLT-05 injects a missing CLI, not an unresponsive daemon (one unregistered probe took ~17 s to a structured error); FLT-08/09 not executed; NaN/Inf/negative evaluator scores still become an unflagged 0.0; Qwen path tested with a fixed evaluator stub, 36 single-sentence injections whose steering effect is not demonstrated, a name-based static guard, replayed-text mutation control, unseeded generation and a client timeout raised to 600 s; the follow-up-question channel is an untested LLM-to-evaluator dependency; the shipped 6 s Qwen client wait is shorter than local generation time (19-30 s) and the UI abandons an evaluation after 20 s; B2 not run; project .venv violates its pins.
