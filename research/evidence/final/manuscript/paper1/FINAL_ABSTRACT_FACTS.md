# Paper 1 - abstract facts (all from stored artifacts; see research/evidence/final/PAPER1_FINAL_CLAIM_MATRIX.md)
- System: LLM-assisted technical-interview practice pipeline (orchestrator, evaluator service, local Qwen 1.5B feedback service, Docker C sandbox, SQLite). Engineering evaluation on one Windows/Docker Desktop (WSL2) machine; no users.
- Method: three campaigns (containment X1-C, fault injection X1-A, Qwen fixed-answer invariance X1-B-I), each with controls; protocols committed and tagged locally before execution; same agent designed, ran and self-audited; two builds (A = first, B = after two repairs), both reported.
- Containment (X1-C): nine attack programs; shipped configuration met the criteria 5/5 per attack on both builds; permissive control breached 5/5 where a control applies; benign 10/10. Qualifiers: static pre-flight blocks only the literal ptrace call (ptrace returned 0 in the container when bypassed); socket() succeeds but connect() fails without a network; the status string did not distinguish contained from breached for four attacks.
- Fault injection (X1-A): build A - nine of twelve scenario rows met 5/5 (FLT-04 counted as four rows), evaluator outage recorded as a 0.0 score with no flag (0/5), compiler timeout left a running container (5/5 runs), one timing-bound miss (FLT-07b 4/5). Build B - every executed scenario 5/5 (evaluator outage fails closed; container removed on timeout). FLT-08 (WebSocket) and FLT-09 (audio) not executed.
- Invariance (X1-B-I): build A - 72 pairs, 16 valid LLM-sourced (registered minimum 30 not met), 72/72 equal; build B - 72 pairs, 72 valid, 72/72 equal, mutation control 72/72, static guard 0 flagged with injected mutant caught. Follow-up-question channel documented, untested. Injections' steering effect not demonstrated.
- Defects and residual limitations: NaN/Inf/negative evaluator scores still become an unflagged 0.0; shipped 6 s Qwen client wait vs 19-30 s local generation; unresponsive-daemon case not campaign-tested (single probe ~17 s to a structured error).
- Required qualifiers: single machine; nine programs; local unpushed tags; not secure/fault-tolerant/isolated; independent review pending.
