# X1 independent-review package (index only)

Prepared 2026-09-20 for an independent methodological review of the X1 campaigns (Paper 1) **before Paper 1 evidence is declared final**. This file is an **index**: it lists artifacts, purposes, hashes and freeze status. It does not restate, rewrite, fix or reinterpret the methodology or the results; every statement about what an artifact says must be checked in the artifact itself. Nothing was executed and no evidence file was changed to produce it. Nothing has been pushed.

**Reviewer context (facts, not arguments).** Every X1 protocol, harness, control, repair and re-test was written and run by the same agent (Claude), and, at the time this package was first prepared, the only review was that agent's self-audit (`X1_METHOD_AUDIT.md`). **Post-review status (added 2026-09-20): an independent, read-only Antigravity methodology review of X1-A, X1-B-I and X1-C has since been completed, verdict METHODOLOGICALLY SOUND ONLY AFTER CLAIM NARROWING, no blocker; it authorizes no rerun or modification of frozen evidence.** The full report is not a repository file; the Paper 1 claim documents were then narrowed (documentation only), which is why several documents below are marked as modified relative to HEAD and their hashes differ from `FINAL_HASH_MANIFEST_FINAL.json`. No result, protocol, harness, build or tag changed. Tags are annotated, local, unpushed and author-controlled ("registered" here means: protocol and harness committed and tagged before the run, not externally timestamped). The v2 (X1-A, X1-C) and v3 (X1-B) protocols were written after the earlier runs' results were seen. Replicates are deterministic reruns, not samples.

**How to read the hashes.** SHA-256 is of working-tree bytes at the time this file was generated. Trees marked `-text` in `.gitattributes` (`research/confirmatory`, `research/analysis`, `research/tools`, `research/locks`, `research/claims`) keep raw bytes; other trees (e.g. `research/evidence`, `agents/`, `services/`, `tests/`) are `text=auto`, so on a CRLF checkout their byte hashes can differ while the committed blobs are unchanged. For those files compare the git blob id (`git rev-parse <tag>:<path>`) instead. **"Frozen?"** means: tracked, no difference from `HEAD`, and `git diff --quiet <tag> -- <path>` succeeds for one or more of the X1/evidence tags (the file is byte-identical to the tagged version); the cell names the earliest such tag and how many tags match. Later tags contain earlier files unchanged, so a long list is not informative. Files created after the last tag (this index) are marked `NO`.
