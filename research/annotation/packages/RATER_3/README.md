# PREPAIred Blinded Evaluation Package — RATER_3

**Target Evaluator:** Independent Technical Expert B (Rater 3)  
**Benchmark Suite:** 64-Case Technical Interview Assessment Suite  
**Version:** 1.0 (Frozen Blinded Protocol)  

---

## Package Contents
1. `README.md`: This instruction document.
2. `SCORING_RUBRIC.md`: The complete evaluation rubric, qualitative anchor bands, and scoring guidelines.
3. `RATING_SHEET_64_CASES.csv`: The blinded spreadsheet containing 64 candidate responses to score.

---

## Evaluation Procedure
1. Review the scoring guidelines in `SCORING_RUBRIC.md`.
2. Open `RATING_SHEET_64_CASES.csv`.
3. For each item (`BM-001` through `BM-064`), assign a score between `0.00` and `1.00` in the `score_0_to_1` column.
4. Do not consult external automated scoring tools or discuss ratings with other reviewers during the evaluation.
5. Once all 64 items are scored, save the CSV file and return it as instructed.
