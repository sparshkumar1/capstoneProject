# PrepAIred — Comprehensive Test Strategy

Built from `Component_Inspection_Map.md` (direct code inspection, Phase 1–2 of this session), not from the generic master-prompt checklist. Every category below is classified for *this* codebase specifically — categories that don't apply to what's actually implemented are marked Not Applicable with a reason, not silently included.

**Legend:** ESSENTIAL = necessary to establish core functionality/a stated project objective works. RECOMMENDED = meaningful additional confidence, feasible with existing data/infra. OPTIONAL = useful if time permits, lower marginal value here. N/A = doesn't apply to this implementation, with reason.

## RL evaluation

**Governing constraint, repeated here because it is easy to violate accidentally:** `CLAUDE.md` forbids retraining PPO or changing reward/state/action definitions without explicit approval, and forbids starting any new X1/X2/X3-style experiment without a preregistered, hashed, git-tagged protocol. Everything below is **inference-only / read-only analysis of the existing frozen checkpoint and frozen Paper-3 results** — not new training, not a new experiment campaign.

| Activity | Priority | Rationale |
|---|---|---|
| Gymnasium environment validation (`rl/env/interview_env.py` — observation/action space shape, reset/step contracts) | **ESSENTIAL** | `test_rl_env.py` already exists; cheap, high-signal, standard Gym-checker-style verification |
| Guardrail rule verification (`rl/guardrails.py`, G-series conditions) | **ESSENTIAL** | This is the component Paper 3 already identified as responsible for essentially all of the measured improvement over Fixed — understanding exactly what it does is more important than re-testing PPO itself |
| Frozen-checkpoint inference sanity check (load `rl/checkpoints/seed_123/ppo_final.zip` + `vecnormalize.pkl`, run `.predict()` on a handful of constructed states, confirm `Discrete(3)` output and VecNormalize is applied) | **ESSENTIAL** | Directly tests the real deployed artifact; low cost, catches silent breakage (e.g., if the checkpoint format changed) |
| Re-analysis of existing frozen Paper-3 results (MAE/volatility table, guardrail-attribution finding) | **ESSENTIAL** (as citation, not re-computation) | Already frozen and audited — cite verbatim from `CANONICAL_SCIENTIFIC_TRUTH_CURRENT.md` §D.2, do not recompute or re-derive new numbers from the frozen checkpoint without a preregistered protocol |
| New PPO training run / new seeds / new ablation | **BLOCKED — requires explicit user approval + preregistration** | Out of scope for Task 1 as currently authorized |
| New XA/XB/XC/XD-style multi-agent coordination experiment | **BLOCKED — out of scope entirely** per the Phase-1 scope decision (`reference_material_analysis/IEEE_Paper_Scope_Decision.md`) | — |

## Known blocker affecting categories A, C, D, F, I, J, K, L

`pytest`/`pytest-asyncio` (listed in `requirements/dev.txt`, pinned, not a new/unlisted dependency) are **not installed** in `.venv`. The install command was blocked by this session's sandbox permission classifier (irreversible-local-destruction gate on `pip install`). This needs either (a) the user running `! .venv/Scripts/python.exe -m pip install -r requirements/dev.txt` themselves, or (b) a permission grant for this session. Until then, categories A/C/D/F/I/J/K/L cannot execute — see the Phase-2 chat summary for the exact ask.
